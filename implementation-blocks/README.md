# Implementation Blocks

The working exercises from *Run It on AI*, published in full. Each file
is one Implementation Block: the prompt the reader runs, the notes their
AI agent follows, and the artifact the exercise produces. These are the
same payloads the `get_implementation_block` tool serves.

- [compounding-question](ch1-how-ai-actually-works--compounding-question.md) — A written compounding question with a one-paragraph answer, saved somewhere findable in under thirty seconds.
- [pre-automation-discipline](ch2-before-you-build-anything--pre-automation-discipline.md) — A verdict on the candidate process: ready / almost-ready / not-ready / MVP it. With next steps.
- [pick-first-automation](ch3-the-ai-tool-landscape--pick-first-automation.md) — A first automation choice with the kind-of-work category named (Plain-and-Simple / AI-Augmented / Agentic).
- [harness-eval](ch4-ai-harnesses--harness-eval.md) — A one-paragraph verdict on a specific harness: install / watch / skip, the one job it is best for, the first concrete step under thirty minutes.
- [find-the-gap](ch5-the-glue--find-the-gap.md) — One named gap between AI output and useful work, plus the simplest connection that bridges it within the existing setup.
- [first-skill](ch6-agents-in-claude-code--first-skill.md) — A draft SKILL.md the reader wrote themselves (not for them), saved under .claude/skills/<task-name>/, run at least once.
